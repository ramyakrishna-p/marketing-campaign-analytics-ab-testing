# Marketing Campaign Analytics & A/B Testing

**Data Analytics | Python, Pandas, SciPy, SQL**

All data is **SYNTHETIC** — generated by `analysis.py` (seed 7). No real campaign data.

## What it does
Analyses channel ROI, CTR and conversion, and runs an A/B test (variant A vs B) with a chi-square test on conversion among clickers.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Results (actual run output)
- Rows: **4,000** | Overall CTR: **0.1715** | Conversion rate (clickers): **0.1837**
- Total cost: **£7,009.21** | Total revenue: **£9,065.21** | Overall ROI: **0.2933**
- Best channel by ROI: **Email (ROI 1.1144, CTR 0.2225, conversion 0.2327)**
- Other channels: Search ROI 0.2882, Social ROI -0.0407, Display ROI -0.7216
- A/B test: A conversion **0.1713** vs B **0.1970**, chi-square **0.5886**, p-value **0.4429** — **not significant at 0.05** on this synthetic sample. Honest reporting: do not ship B on this evidence alone; run longer.
